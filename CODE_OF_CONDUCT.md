# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussions about the work. Report unacceptable
behaviour privately through [GitHub security advisories](https://github.com/adginr/google-ads-rest/security/advisories/new)
or to the maintainer listed on the GitHub profile. Reports are handled confidentially.
